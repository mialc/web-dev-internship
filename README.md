# Web Dev Internship

Front-end web development work from my internship at US Hunger. I came in with a coding background and worked through HTML, CSS/Bootstrap, and vanilla JavaScript in order, building on the same portfolio site at each stage. This repo collects that progression.

## Projects

**Ticket 1 - Nonprofit landing page mockup**
HTML/CSS practice building a static landing page layout.
Own repo: https://github.com/mialc/nonprofit-landing-mockup

**Live portfolio site**
My current personal developer portfolio - HTML, CSS, Bootstrap, and vanilla JS, including a project dashboard with search/filter/sort and localStorage.
Own repo: https://github.com/mialc/mia-portfolio

**portfolio-v1-bootstrap**
Early snapshot of the portfolio: HTML, CSS, and Bootstrap only, no JavaScript yet.

**portfolio-v2-js**
Snapshot after adding the first round of vanilla JavaScript: mobile nav toggle, FAQ accordion, contact form validation, dynamic intro-text button.

**frontend-resource-library**
The most current project: a modular vanilla JS app that loads learning resources from a local JSON file with fetch/async/await, and supports search, filtering, favorites (localStorage), and loading/error states. See its own README for details.

**Flex Example**
A small standalone CSS flexbox practice exercise.

## Background

Learning order: HTML -> CSS/Bootstrap -> JavaScript, going from static pages to interactive features to a data-driven modular app. Working toward WordPress theme development next.
