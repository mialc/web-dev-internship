# Web Dev Internship

Front-end web development work from my internship at US Hunger. I came in with no coding background and worked through HTML, CSS/Bootstrap, and vanilla JavaScript in order, building a small project at each stage. This repo collects that progression.

## Projects

**Ticket 1 - Nonprofit landing page mockup**
HTML/CSS practice building a static landing page layout.
Own repo: https://github.com/mialc/nonprofit-landing-mockup

**Ticket 2 - Personal portfolio site**
HTML, CSS, and Bootstrap. My personal developer portfolio, still actively maintained.
Own repo: https://github.com/mialc/mia-portfolio

**Ticket 3 - JS**
First vanilla JavaScript work, built on top of a copy of the portfolio site: mobile nav toggle, FAQ accordion, contact form validation, and a dynamic intro-text button.

**Ticket 4 - Dashboard**
A JavaScript project dashboard that renders, filters, searches, and sorts an array of project objects, with localStorage persistence.

**frontend-resource-library**
The most current project: a modular vanilla JS app that loads learning resources from a local JSON file with fetch/async/await, and supports search, filtering, favorites (localStorage), and loading/error states. See its own README for details.

**Flex Example**
A small standalone CSS flexbox practice exercise.

## Background

Learning order: HTML -> CSS/Bootstrap -> JavaScript, going from static pages to interactive features to a data-driven modular app. Working toward WordPress theme development next.
