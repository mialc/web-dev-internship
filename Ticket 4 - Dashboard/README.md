# Portfolio Project Dashboard

## Project Overview
Ticket 4 reviews creating a JavaScript dashboard that dynamically loads arrays of objects into the page based off the users selection. The project includes filter buttons that help dynamically update the state and then re-renders to show the projects that were selected based off an active class/state.

## Features
- Render projects from JavaScript data
- Filter projects
- Search projects
- Sort projects
- Add new projects with a form
- Save projects with localStorage
