# Front-End Resource Library App

## Project Overview
Built a modular vanilla JavaScript Front-End Resource Library App that loads resources from a JSON file, renders resource cards dynamically, supports search and filters, saves favorites to localStorage, uses event delegation, handles loading/empty/error states, and organizes code using JavaScript modules.

## Features
Still in progress, search works, filters and favorites are next.

- Load resources from a JSON file
- Render resource cards dynamically
- Search resources
- Filter by topic (in progress)
- Filter by difficulty (in progress)
- Save favorite resources (in progress)
- View favorite resources (in progress)
- Handle loading, empty, and error states (in progress)
- Use JavaScript modules

## File Structure
- `index.html` - page shell and container elements, loads main.js as a module
- `data/resources.json` - the resource data
- `assets/css/styles.css` - styling
- `js/api.js` - fetches and parses the resource data
- `js/render.js` - builds and renders the resource cards
- `js/filters.js` - search and filter logic
- `js/favorites.js` - favorite/unfavorite logic
- `js/storage.js` - localStorage helpers
- `js/main.js` - coordinates everything and wires up events
